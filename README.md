# AgroResQ
AgroResQ is a console-based disaster and agriculture management system developed for the Software Development Project (SDP 100).

## Disaster Management Module
Current features:
- Register disaster information
- Select disaster type, location, severity, and status
- Input validation for user data

## Technologies Used
- C++
- Structures
- Functions
- Arrays
